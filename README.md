# TES_UE52
This is the code base to analyze data obtained from the Transition Edge Sensor located at UE52_SGM at BESSY II. The code is written in Python. To facilitate and ease the data processing, the data analysis methodology is divided into the following methodology.
1. Preprocessing
   The preprocessing code unifies and collects all the relevant datasets from the raw detector data and the beamline data to build a more accessible RIXS plane dataset.
